# Console Calculator

Интерактивный консольный калькулятор на Python с поддержкой расширенных математических операций, цветовым форматированием вывода в терминале и локальным сохранением истории вычислений в JSON.

## Функциональность

* **Базовые операции:** сложение, вычитание, умножение, деление, возведение в степень, остаток от деления.
* **Инженерные функции:** вычисление квадратного корня, логарифмов и тригонометрических функций (на базе стандартного модуля `math`).
* **История вычислений:** автоматическая запись выполненных операций с временными метками в локальный файл `calculator_history.json`, просмотр и очистка истории.
* **Обработка ошибок:** защита от деления на ноль, некорректного пользовательского ввода и выхода за область определения математических функций.
* **Интерфейс:** цветной вывод меню, результатов и сообщений об ошибках с использованием ANSI-последовательностей.

## Требования

* Python 3.8 или выше.
* Внешние зависимости не требуются (используется только стандартная библиотека Python: `math`, `json`, `os`, `datetime`, `sys`).

## Запуск

```bash
git clone https://github.com
cd console-calculator
python calculator.py
```
